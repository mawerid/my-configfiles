---
name: close-cycle
description: Reconcile a finished roadmap cycle, review documentation drift and prepare the next cycle.
---

Identify the cycle, included plans, acceptance criteria, deferred items and release obligations. Verify each against landed changes. Give every open item an owner and destination. Keep the cycle open if required evidence is missing.
Review the cycle's design and user documentation against current behavior. Reconcile changelog entries, decisions, glossary and project state. Compress completed roadmap detail into an outcome with links, then open the agreed next milestone. Surface proposed scope changes for decision.
Hand off to release when a release is due and to refactor-review when structural debt warrants a review. Report remaining actions and their owners.
