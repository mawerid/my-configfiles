---
name: retro
description: Review a session or plan for recurring friction and propose evidence-backed improvements.
---

Use the current conversation by default. For explicitly authorized Claude transcript access, run the adjacent session-digest from the project root with --session ID, --slug SLUG or --last N. For Codex use the conversation or a user-provided transcript. Respect project and privacy boundaries.
Identify repeated corrections, expensive navigation, missed checks, misleading instructions, model-tier mismatches, repeated tool calls and missing information. Tie each candidate to observed evidence and describe its effect.
Rank improvements by impact. For each, identify the smallest edit or automated check, its cost and how to tell if it worked. Apply accepted items within approved scope; commit only when requested.
