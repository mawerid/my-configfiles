# Step difficulty and delegation

Tier 1 covers local mechanical changes with an obvious check. Tier 2 covers ordinary implementation across modules and behavioral tests. Tier 3 covers design uncertainty, expensive mistakes and independent review. Mark a step with its grade and an explicit tier override when needed.

Use the current tool's configured explorer for investigation, implementer or tester for execution, and planner or reviewer for high-judgment work. When model selection is supported, use a locally available lightweight, standard or strongest reasoning model respectively. Verify availability before dispatch and report any substitution for approval. Pass explicit context when selecting a fresh model. With no delegation available, execute sequentially and disclose when independent review is outstanding.
